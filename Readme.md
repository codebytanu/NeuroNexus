# NeuroNexus Registration Form

![Form Preview](https://i.imgur.com/JQ7X9Kl.png) *(Replace with your own screenshot)*

A sleek, glassmorphic web form for NeuroNexus Innovations' internship task. Built with **HTML5 and CSS3**, this form collects user details with intuitive UI interactions.

## ✨ Features
- **Glassmorphism Design**: Frosted glass effect with backdrop blur.
- **Responsive Layout**: Adapts to mobile and desktop screens.
- **Interactive Elements**:
  - Hover/focus effects on inputs.
  - Animated gradient submit button.
  - Custom-styled radio buttons.
- **Validation**: HTML5 client-side validation (required fields).
- **No JavaScript**: Pure HTML/CSS implementation.

## 🛠️ Technologies Used
- HTML5
- CSS3 (Flexbox, Gradients, Transitions)
